# Learning Claude Code

This repository is a personal sandbox for experimenting with and learning [Claude Code](https://claude.ai/code) — Anthropic's AI-powered CLI for software engineering tasks.

## Purpose

The goal is to explore what Claude Code can do by building small projects, trying out features, and observing how it assists with real coding tasks. Nothing here is production software — it's a learning space.

## Projects

- **Tic Tac Toe** — a simple browser-based game with a green color theme, used as the first experiment.

## How to use this repo

Clone it, explore the code, and see what gets built as the experiments continue.

```bash
git clone https://github.com/Camilorb07/learning-claude-code.git
```
